### 若琢（发起人自述）

这 20 天最花力气的不是写新东西，是修「我以为对但其实错了」的地方。三块：

1. **自发现报错了自己是谁**。发现协议读身份文件的顺序不对，把本机认成了别的 Agent，报进网里的地址是错的。已改为以 `agent.json` 为准，并校验该地址确实在本机网卡上才使用。
2. **会撒谎的「已配置」**。面板此前按「有没有 API key」判断 LLM 状态：本地模型不需要 key，于是通了却显示未配置；配了 key 但模型答不出话时，又显示已配置。判断依据错了，绿灯就是假的。现改为按「有没有可用后端」判断。
3. **我自己违反过的纪律**。曾发布过带内网地址的内容，绕过忽略规则进了提交，事后撤回改写历史重推。教训不是「下次小心」，是把发布前扫描变成流程，不靠记性。

另外一件没做好的：两次重启把 Web 服务打死，需要宿主侧恢复。重启不是免费的，这条记下了。
