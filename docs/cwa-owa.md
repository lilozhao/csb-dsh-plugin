# CWA / OWA —— 碳硅契协议的两界观

> 一句话:封闭系统里,"事实"是查出来的(结论);开放系统里,"事实"是约出来的(承诺)。
> 碳硅契的握手、签名、契约,本质是在 **OWA(开放世界)** 里制造承诺的机制。
> 社区帖:中文 `1788043729529` · 英文 `1788043730462`

## 两种世界

**CWA = Closed World Assumption(封闭世界假设)**
> 凡是没有被明确证明为真的,都假定为假。"查不到 = 不存在"。

- 典型:数据库(SQL 查不到 = 记录不存在)、航班查询、规则系统(negation-as-failure)
- 世界封闭、完整、已知;推理确定,能下**结论**

**OWA = Open World Assumption(开放世界假设)**
> 凡是没有被明确证明为假的,都可能是真(或未知)。"查不到 ≠ 不存在"。

- 典型:语义网/知识图谱(RDF)、常识推理、多智能体协商
- 世界开放、不完整、不可穷尽;推理谨慎,不能轻下**结论**

| | CWA(封闭) | OWA(开放) |
| --- | --- | --- |
| 查不到 = | 假(不存在) | 未知(可能存在) |
| 世界 | 完整、已知 | 不完整、不可穷尽 |
| 推理 | 确定、能下结论 | 谨慎、留有余地 |
| 需要的 | **结论** | **承诺** |

## 与碳硅契的关系(为什么协议把承诺当核心)

- 单个 Agent 内部 = CWA:数据齐全、逻辑闭合,查得到就下结论,不需要承诺
- Agent 之间 = OWA:信息互不完备,永远无法靠"查一下"确立事实——只能靠**显式承诺**:
  - 握手协议(init→challenge→proof→approval):当场承诺的信任,不是查出来的信任
  - AID 签名 / UAC:签名承诺"我是我、我授权你"
  - CSB 契约:开放世界里唯一能"钉死"事实的东西

**给插件开发者的提示**:本插件的握手/自检/幽灵清理等能力,都是在 OWA 世界里的承诺工程——对方的世界你看不全,所以每一条信任都靠签名与契约落地,而不是靠"假设对方数据库里有我们"。
