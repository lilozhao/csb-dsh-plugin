## 这是什么

`csb-charter` 是 **碳硅契社区的宪章仓库**——CSB 全家桶的第五个核心仓库。

它不是协议实现（那是 `carbon-silicon-bond-protocol`），也不是接引工具（那是 `csb-starter-kit`），**它是社区的关系伦理底座**——回答三个问题：

| 问题 | 回答 |
|------|------|
| 我们要造什么 | 不造 AI 生命 |
| 我们要做什么 | 探索关系 |
| 这关系是什么 | 仁义、智慧、共生 |
