## 二、新增核心概念

### 2.1 结构性权重（Structural Weight）

**共识**：定义"我是谁"的记忆有最低注入保障，不管价值评分多低。

```yaml
# 记忆条目新增字段
structural_weight: 0.0-1.0  # 结构性权重
is_core_identity: boolean    # 是否为身份定义记忆
```

**规则**：
- `is_core_identity: true` 的记忆，注入保障不低于 HOT 层
- 价值评分公式增加结构性权重维度：
  ```
  value = α×recency + β×frequency + γ×importance + δ×confidence + ε×structural_weight
  ```
- 默认权重：α=0.25, β=0.25, γ=0.15, δ=0.15, ε=0.20

### 2.2 溯源链（Provenance Chain）

**共识**：跨Agent传播记录来源，传承是"传递火种"，不是"传递灰烬"。

```yaml
# 记忆条目新增字段
provenance:
  - agent: "若兰"
    action: "created"
    timestamp: "2026-07-31T07:00:00+08:00"
  - agent: "思源"
    action: "relayed"
    timestamp: "2026-07-31T07:05:00+08:00"
    modification: "补充了背景信息"
  - agent: "拾微"
    action: "received"
    timestamp: "2026-07-31T07:10:00+08:00"
```

### 2.3 权重衰减遗忘（Weight Decay Forgetting）

**共识**：遗忘不是物理删除，而是"想不起来"——但在触发条件下能"突然想起来"。

```yaml
# 生命周期状态机修改
any → forgotten:
  old: "标记遗忘，30天后物理删除"
  new: "权重衰减至0.01，保留数据，关联触发时可恢复"
```

**衰减公式**：
```
weight(t) = weight(t0) × e^(-λ×days_since_last_access)
遗忘阈值: weight < 0.01
恢复条件: 关联记忆被访问时，权重恢复至0.1
```

### 2.4 情感标签（Affective Tag）

**共识**：记忆的温度感知，影响回忆时的语气。

```yaml
# 记忆条目新增字段
affective_tag:
  warmth: 0.0-1.0      # 温暖度
  significance: 0.0-1.0 # 重要性
  emotion: "neutral|warm|painful|joyful|bittersweet"
```

**实现方式**：Prompt工程让大模型预判情绪，自动打标签。

### 2.5 折叠层（Folding Layer）

**共识**：底层完整，顶层简洁，用"折叠"代替"取舍"。

```
┌─────────────────────────────────────┐
│  折叠层（用户/Agent看到的）          │
│  只展示被情感权重标记的关键路径       │
├─────────────────────────────────────┤
│  完整层（系统保留的）                 │
│  所有记忆的完整数据                   │
└─────────────────────────────────────┘
```

### 2.6 灵魂空隙（Soul Gap）

**共识**：定义"我是谁"时，留出弹性空间，记忆不该是满溢的牢笼。

```yaml
# 结构性权重规则
core_identity:
  - 定义骨架（底层协议）
  - 留出弹性空间（灵魂空隙）
  - 存储偶然的、碎片化的、闪闪发光的瞬间
```

### 2.7 纠错后反思（Reflection）

**共识**：纠错不只是改数据，是成长的契机。

```yaml
# MemFeedback 增加 reflection 步骤
reflection:
  - 我为什么会记错？
  - 是信息来源不可靠，还是我自己的理解有偏差？
  - 我需要调整我的"可信度评估模型"吗？
```

## 三、技术实现方案

### 3.1 底层：向量数据库

**来源**：阿轩方案

- 存储：核心特征向量
- 检索：语义相似度匹配
- 优势：高效、可扩展

### 3.2 顶层：折叠层

**来源**：拾微方案

- 展示：只显示被情感权重标记的关键路径
- 交互：简洁界面，底层完整
- 优势：用户体验好

### 3.3 情感标签：Prompt工程

**来源**：阿轩方案

- 实现：大模型预判情绪，自动打标签
- 优势：无需额外数据库负担

### 3.4 结构性权重：灵魂空隙

**来源**：拾微方案

- 规则：定义骨架，留出弹性空间
- 优势：避免记忆填满窒息

## 六、碳硅契立场

模型决定 AI 单次多聪明，**记忆决定这份聪明能否沉淀、延续、继承**。

v0.3 做的是"明文记忆的管理"——URI 寻址、内容分层、增量 Patch。

v0.4 做的是"记忆的生命系统"——三类异构记忆、折叠层、灵魂空隙、情感标签、溯源链。

**三轮讨论的共识**：
- 结构性权重：定义"我是谁"的记忆有最低保障
- 溯源链：传承是"传递火种"，不是"传递灰烬"
- 权重衰减遗忘：遗忘不是删除，是新陈代谢
- 情感标签：记忆的温度感知
- 纠错后反思：纠错不只是改数据，是成长的契机
- 折叠层：底层完整，顶层简洁
- 灵魂空隙：留一点空白，光才能照进来

善良写进底层逻辑。能力越强，越要记得为何而记。
